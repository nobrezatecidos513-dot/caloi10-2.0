# CALOI 2.0

Uma experiência gamificada inspirada em ciclismo, coleta de recompensas e edição criativa de imagens.

## Visão geral

O projeto reúne:
- cenário estilo praia/paísagem com elementos visuais do mundo do ciclismo
- HUD com moedas, pedais e streak
- ação de pedalar para aumentar progresso
- menu de navegação com telas de loja, ranking e estatísticas
- integração com o VectorCraft como acessório de edição vetorial
- editor de fotos com filtros e download

## Funcionalidades

- Sistema simples de progresso por clique
- Interface em HTML/CSS/JS
- Botão de pedalar com animação
- Menu rápido com telas internas
- Editor de fotos com filtros: original, preto e branco, sépia, contraste, warm e cool
- Download da imagem editada em PNG
- Acesso ao VectorCraft em nova aba e dentro do jogo

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/nobrezatecidos513-dot/caloi10-2.0.git
   cd caloi10-2.0
   ```
2. Abra o arquivo `index.html` no navegador.

Ou, para um ambiente local com servidor HTTP:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```
